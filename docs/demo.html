    Setup

    Two commands, then one sentence

    your Flutter project
    $ flutter pub add fixkit $ dart run fixkit init ✔ lib/main.dart runApp(FixKit(child: ...)) ✔ Launcher .fixkit/mcp.dart ✔ Cursor .cursor/mcp.json + Dart MCP server ✔ VS Code .vscode/mcp.json ✔ Antigravity ~/.gemini/config/mcp_config.json ✔ Hot reload on save ✔ Agent rules AGENTS.md ✔ Hub running on 127.0.0.1, port 4747
    Reload the editor once, run the app, then tell the agent: watch for fixes
    What you get

    No marks, no addresses, no config

    Source lines
    Debug builds record where every widget is constructed, so each report names the exact file:line without annotating anything.
    Devices
    iOS simulator, desktoploopback Android emulator, USB phoneadb reverse, automatic iPhone over Wi-Fiinit --lan, with a token
    Hot reload
    Reload on save, the Dart MCP server's hot_reload, or dart run fixkit run. The app confirms each reload itself.
    Live and light
    The card shows each step the moment the hub hears of it. The overlay uses Flutter's own ValueNotifiers and painters, with no blur, so your app never rebuilds because of it.
    No agent watching
    The request goes to your clipboard with a desktop notification, ready to paste into any chat.
    Prototype of the fixkit for Flutter in-app UI and flow. Based on ostiums/fixkit.
